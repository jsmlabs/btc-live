# Support

BTC Live is a small open-source browser extension focused on public BTCUSDT Spot market data.

## Bug Reports

Use GitHub Issues for reproducible problems with existing BTC Live behavior.

A useful bug report should include:

- BTC Live version
- Browser and browser version
- Observed behavior
- Expected behavior
- Steps to reproduce
- Relevant console errors
- Screenshots or additional context when useful

Use the repository bug report template where available.

## Browser and Compatibility Issues

Compatibility reports are welcome for:

- Google Chrome
- Microsoft Edge
- Brave
- Mozilla Firefox
- Other Chromium-based browsers

For compatibility issues, include the exact browser version and operating system.

## Binance Market-Data Issues

If BTC Live cannot load or maintain Binance Spot market data, include:

- Whether the failure affects REST initialization, WebSocket updates, or both
- The connection status shown by BTC Live
- Relevant console or network errors
- Whether the issue is reproducible on another network or browser

Do not include Binance account credentials, API keys, wallet data, or other secrets. BTC Live does not require them.

## Security Issues

Do not publish sensitive exploit details in a public issue.

See [SECURITY.md](SECURITY.md) for the project's security model and reporting guidance.

## Feature Requests

Feature requests may be discussed separately, but they are not eligible for the v1.0.x maintenance line.

The v1.0.x branch is limited to bug fixes, compatibility corrections, security fixes, build/release fixes, and required store-policy adjustments.

See [MAINTENANCE.md](MAINTENANCE.md).

## Scope of Support

BTC Live provides market-data display software only.

The project does not provide:

- Trading or investment advice
- Trading signals
- Portfolio management
- Exchange account support
- Binance account support
- Wallet support
- Recovery of funds, accounts, or credentials

Market data is provided by Binance public Spot market-data services. BTC Live is not affiliated with or endorsed by Binance.
