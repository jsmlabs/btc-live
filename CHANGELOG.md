# Changelog

All notable changes to BTC Live are documented here.

The project follows Semantic Versioning.

## [1.0.0] - 2026-10-02

### Added

- BTCUSDT Spot last-trade live price
- Binance REST initialization and recovery snapshot
- Binance `btcusdt@trade` live stream
- Binance `btcusdt@ticker` rolling 24h stream
- 24h price change, high, low, and quote volume
- best bid, best ask, and spread
- LIVE, STALE, RECONNECTING, OFFLINE, and ERROR states
- deterministic reconnect backoff
- compact dark-mode popup
- local display settings
- reduced-motion support
- Chromium and Firefox build targets
- deterministic ZIP packaging without third-party dependencies
- automated formatting, validation, state, and backoff tests
- privacy and security documentation
